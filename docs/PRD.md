## 1. 背景与问题

普通投资者（散户）在做美股 / 加密决策时面临三个痛点：

1. **信息过载**：每天海量新闻、财报、社交媒体讨论，无法快速判断哪些与持仓相关、是利好还是利空。
2. **工具门槛高**：专业量化平台（backtrader、QuantConnect、freqtrade）要求会写代码、懂统计，散户用不起来。
3. **决策情绪化**：缺乏系统化信号和回测验证，容易追涨杀跌。

**机会**：FinBERT 等本地情绪模型成熟 + 向量化回测引擎（vectorbt）普及，使"把专业量化能力包装成普通人能用的可视化工具"成为可能——用户不写代码，也能获得**技术指标 + 新闻情绪**的、**可解释**的信号和回测结果。

## 2. 产品目标与定位

**一句话定位**：QuantCompass 让不懂代码的普通人，也能用"技术指标 + 新闻情绪"系统化地看清美股和加密的市场方向。

**核心价值主张**：
- 把分散的行情 / 新闻 / 情绪**聚合成一眼能看懂的信号**（指明方向）。
- 提供**可解释**的理由（"为什么给出这个信号"），而非黑箱。
- 内置**回测**，让用户在投入真金白银前先看历史表现。
- 强调**辅助决策的数据工具**，不替用户下单（合规与信任底线，见第 9 节）。

**QuantCompass 不是什么**（避免错位）：
- ❌ 不是自动交易机器人（不接实盘下单）。
- ❌ 不是投资顾问 / 不提供投资建议（合规要求）。
- ❌ 不是面向专业量化的编程平台。

## 3. 目标用户

| 画像 | 描述 | 核心诉求 |
|------|------|---------|
| **小白投资者** | 有美股 / 加密账户，靠新闻和朋友推荐做决策 | 看懂"现在该关注什么"，避免踩雷 |
| **进阶散户** | 会看 K 线和基本面，想要系统化信号验证判断 | 信号 + 回测，验证 idea |
| **学习者** | 想入门量化但被代码门槛劝退 | 低门槛体验量化思路 |

**非目标用户**：专业机构、需要超低延迟 / 高频的用户、需要自定义复杂策略代码的量化工程师。

## 4. 范围与 MVP

### 4.1 MVP（第一版必须有）
- 自选标的 watchlist 管理（美股 ticker + 加密交易对统一管理）
- 每个标的的 **K 线 + 核心技术指标可视化**（均线、RSI、MACD、动量）
- 每个标的的**每日新闻情绪聚合 + 情绪评分**（可解释：列出关键新闻）
- **量化信号卡片**：技术信号与情绪信号**分开展示**（不揉成黑箱），各自给"关注 / 中性 / 谨慎"提示 + 历史命中率
- 简易**回测**：在 3~5 个内置策略上展示历史收益 / 最大回撤 / Sharpe / 胜率曲线 vs 基准
- 风险提示与免责声明（贯穿全程）

### 4.2 后续迭代（明确排除在 MVP 外）
- 策略自定义（no-code 策略构建器）
- 组合层面分析与再平衡
- 实盘交易接口（需券商 / 交易所对接 + 更强合规）
- 提醒推送、移动端 App、社区 / 策略分享

## 5. 功能需求

### F1. 自选标的管理
- 添加 / 删除 / 分组自选标的；支持搜索美股 ticker 与加密交易对（如 BTC/USDT）。
- 列表展示价格、当日涨跌、技术信号 + 情绪分概览。
- **统一抽象**：美股与加密在 UI 上一致，差异（交易日历、复权、7×24、时区）由数据层吸收。

### F2. 行情与技术指标可视化（核心）
- 交互式 K 线图（缩放、时间段切换），叠加均线 / RSI / MACD / 动量等指标。
- 指标参数可调（如均线周期），变更后图表与信号实时刷新。
- 关键术语带 tooltip 解释（什么是 RSI、什么是动量）。

### F3. 新闻情绪聚合（核心）
- 自动拉取每个标的的相关新闻（带**精确发布时间戳 UTC**）。
- 用 **FinBERT** 为每条新闻打分，聚合成标的级**日度情绪分**。
  - ⚠️ 采用 FinBERT 输出的**连续概率 / logits**，而非 positive/neutral/negative 三分类标签（实证：三分类裸情绪常跑输，连续分更有 alpha，见第 10 节）。
- **可解释**：点击情绪分可展开当日驱动该分数的关键新闻标题、来源、链接、单条情绪。
- 处理"无新闻"情况：标记为中性，不误导。

### F4. 量化信号卡片（核心）
- **技术信号**与**情绪信号分开输出**，各自给分级提示（积极关注 / 中性 / 需谨慎），再给一个组合视图。
- 每个信号附**理由说明**（哪些因子在起作用），强调"仅供参考"。
- 明确展示信号的**历史命中率**（来自回测），避免"一定准"的错觉。

### F5. 回测（核心）
- 提供 3~5 个内置策略（如"双均线 + RSI""动量 + 波动率过滤""情绪 + 动量"）。
- 用户选标的 + 时间段 + 策略，一键回测。
- 输出：累计收益曲线 vs 基准（美股 SPY / 加密 BTC）、年化收益、最大回撤、Sharpe、胜率、交易次数。
- **必须默认扣除手续费和滑点**，避免理想化结果。
- 显著标注**前视偏差与过拟合风险**（见第 10 节）。

### F6. 合规与教育模块
- 全程免责声明；首次使用强制阅读"这不是投资建议"。
- 内置简短概念解释（什么是情绪分、什么是回测、为什么历史不代表未来）。

## 6. 用户流程（MVP 主流程）

```
进入 / 登录
  → 添加自选标的（美股 / 加密）
    → 查看标的详情页：K 线 + 技术指标 + 情绪分（方向） + 信号卡片（含理由）
      → 展开查看驱动新闻（可解释）
      → 点击"回测这个信号" → 选时间段 / 策略 → 看历史表现（扣费后）
```

## 7. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 详情页加载 < 2s；回测结果 < 10s 返回（向量化回测） |
| 数据新鲜度 | 新闻情绪每日至少更新 1 次；价格可用延迟数据（标注延迟） |
| 可用性 | 面向小白，零代码、零术语门槛，关键术语都有 tooltip |
| 可解释性 | 任何信号 / 分数都能下钻到原始依据 |
| 时间一致性 | 全系统时间戳统一 UTC、tz-aware（美股加密混用，防时区 bug） |
| 安全 | API key 服务端保管，不下发客户端 |
| 成本 | 数据源按额度计费，需缓存 + 限流控制单用户成本 |

## 8. 技术方案

### 8.1 技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 语言 / 依赖 | Python 3.11+ / `uv` | 量化生态在 Python；uv 快且锁文件可复现 |
| 美股行情 | `yfinance`（研究期）→ Polygon / Alpaca | 免费起步；注意 yfinance 不可商用 |
| 加密行情 | `ccxt` | 统一接口对接多交易所 |
| 交易日历 | `pandas-market-calendars` | 处理美股交易日；加密 7×24 不用 |
| 数据存储 | Parquet + `duckdb` | 列式、point-in-time 查询快 |
| 技术指标 | `pandas-ta` | 纯 Python，好装 |
| 新闻情绪 | `transformers` + FinBERT（`ProsusAI/finbert`） | 本地、便宜、**无前视偏差** |
| 回测 | `vectorbt` | 向量化、极快，适合可视化工具批量分析 |
| 可视化 | **Streamlit + Plotly** | 研究阶段最快出交互式图表；产品化再换前端 |
| 配置 | `pydantic-settings` + `.env` | API key 不进版本库 |

> 参考开源蓝本：`marketcalls/vectorbt-backtesting-skills`（含美股 + 加密、成本建模、QuantStats 报告、12 个策略模板）；`IsaacCheng9/quant-trading-strategy-backtester`（含均值回归 / 配对 / walk-forward）。

### 8.3 数据源候选

| 类型 | 美股 | 加密 |
|------|------|------|
| 行情 | yfinance / Polygon / Alpaca | ccxt（Binance 等） |
| 新闻 + 情绪 | Alpha Vantage / EODHD | CryptoPanic（可免费抓） / The Tie（point-in-time，机构级） / Messari |
| 链上（加密专属，后续） | — | Santiment / Glassnode / Nansen |

> 数据层设计原则：**原始数据落地（带 UTC 时间戳）与使用分离**。新闻 schema 至少含 `symbol, published_at(UTC), source, headline, body, url, sentiment_score`；情绪分单列、可重算。

## 9. 合规与风险声明（务必重视）

面向普通用户的金融工具，合规是**生死线**：

1. **定性为"信息 / 数据工具"而非"投资顾问"**：不提供个性化投资建议，不承诺收益，避免触发投顾监管（美国 SEC/FINRA RIA）。
2. **全程免责声明**：所有信号、回测、情绪分旁注明"仅供参考，不构成投资建议，投资有风险"。
3. **不替用户决策 / 下单**：降低法律责任与信任风险。
4. **历史不代表未来**：回测页面强制展示。
5. **数据合规**：遵守各数据源商用授权条款（yfinance 不可商用，仅限研究）。
6. **隐私**：用户持仓 / 自选属敏感数据，需合规存储与隐私政策。

## 10. 技术风险与对策（含实证依据）

| 风险 | 影响 | 对策 |
|------|------|------|
| **前视偏差（look-ahead bias）** | 回测虚高、实盘失效 | 情绪打分用本地 FinBERT 而非 LLM API（LLM "记得"历史走势）；信号严格用 point-in-time 数据；优先选 point-in-time 数据源（如 The Tie） |
| **裸情绪分预测力弱** | 单用情绪信号不赚钱 | 实证：三分类 FinBERT alpha 约 -1.73%，连续分模型可达 +23.67%；裸情绪需与技术指标组合（Sharpe 0.50 → 0.78）。故采用**连续情绪分 + 技术指标组合** |
| **市场是预期型而非反应型** | 新闻情绪常滞后 | 不夸大情绪为强领先指标；明确展示其历史命中率 |
| **加密动量 edge 衰减** | 纯价格动量失效 | 引入波动率过滤、特质性信号（如 BTC-中性残差均值回归） |
| **过拟合** | 历史好看、未来失效 | walk-forward 样本外测试；展示扣费后真实表现；不过度宣传 |
| **数据质量** | 缺失 / 重复 | 入库前校验断言；去重；缺口检测 |
| **数据成本失控** | API 费用激增 | 服务端缓存、按标的池共享、限流 |
| **用户误解信号为"稳赚"** | 信任崩塌 + 合规风险 | 强可解释 + 命中率展示 + 免责声明 |

## 11. 成功指标（North Star & 辅助指标）

- **North Star**：每周活跃使用信号 / 回测功能的用户数（WAU on core features）。
- 辅助：自选标的平均数量、回测使用率、新闻下钻点击率、7日 / 30日留存、单用户数据成本。
