## 1. 命名内核

**Pulse = 市场脉搏。** 新闻与情绪是市场跳动的"脉搏"，Pulse 把嘈杂、过载的信息转化为普通人看得懂的节律信号。

- 一个单词，人人会念，无术语门槛 —— 契合"面向普通投资者"的定位。
- "脉搏"自然呼应产品核心（新闻情绪聚合），并延伸到功能命名（如"脉搏异动提醒"）。
- 气质：**亲和、易懂、现代**，而非专业冷感。

## 3. 品牌调性

- **亲和易懂**：零代码、零术语门槛，关键概念都有解释。
- **可信克制**：不夸大收益、不承诺"稳赚"，全程免责声明（呼应合规底线）。
- **数据为主角**：界面安静、数字清晰（详见设计系统 `design.md`，ElevenLabs 风格的单色基底 + 克制用色）。

## 4. 命名/口径规范

- 产品名统一写作 **Pulse**（首字母大写，其余小写）。
- 功能可借用"脉搏 / pulse"语义：如「脉搏异动提醒」「情绪脉搏」。
- 对外文案口径：定性为**信息工具**，不是"投资顾问"、不提供"投资建议"。

## 5. 待定项

- Logo / 视觉标识（结合 `design.md` 的设计系统进一步设计）。
