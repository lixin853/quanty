# 品牌备忘：QuantCompass（量化罗盘）

| 项目 | 内容 |
|------|------|
| 产品名称 | **QuantCompass**（量化罗盘） |
| 主 Slogan | Quant, pointed your way.（量化，为你指明方向） |
| 类别 | 面向普通人的量化分析 / 数据可视化工具 |
| 标的 | 美股 + 加密货币 |
| 日期 | 2026-06-20 |

---

## 1. 命名内核

罗盘指引方向、却不替你走路 —— **QuantCompass** 用「技术指标 + 新闻情绪」为普通人在嘈杂市场中**指明方向**，但只辅助决策、不替用户下单（呼应合规底线）。

- **Quant**：点明专业内核（量化、技术指标、回测、情绪信号）。
- **Compass**：罗盘 / 指南针，给迷茫的散户指明方向；天然呼应"辅助决策、不替你下单"的产品定位与合规底线。

## 2. Slogan

- **主 Slogan**：*Quant, pointed your way.*（量化，为你指明方向）
- **备选**：
  - *Navigate the market with confidence.*（自信地导航市场）
  - *See the signal, not the noise.*（只看信号，过滤噪音）
  - *Your compass for stocks & crypto.*（你的美股与加密罗盘）

## 3. 品牌调性

| 维度 | 取向 |
|------|------|
| 性格 | 可信赖、亲和、不极客；像一个懂行又耐心的向导 |
| 反面 | 不神秘、不承诺暴富、不黑箱、不替你做决定 |
| 关键词 | 方向感、清晰、可解释、过滤噪音、低门槛 |

## 4. 视觉方向（建议）

- **核心符号**：罗盘 / 指南针指针（可抽象为一个指向的箭头或 N 极指针）。
- **可延展**：指针 + K 线 / 折线的结合；"真北"作为视觉锚点。
- **配色建议**：以沉稳的深蓝（信任、金融）为主，辅以一个高亮色作为"指针方向"的强调色。
- **避免**：过度使用红绿涨跌色作为主色（留给数据本身），以免品牌色与行情色冲突。
